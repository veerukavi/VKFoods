# VK Foods – South Indian Catering Website

**From Our Kitchen to Your Soul**

## Setup

1. **Update WhatsApp Number** in `js/script.js`:
   ```js
   whatsappNumber: "919876543210",  // Replace with your number
   ```

2. **Change Admin Password** in `admin/admin.js`:
   ```js
   password: "vkfoods@2024",  // Change this
   ```

3. **Deploy to GitHub Pages**: Go to Settings → Pages → Deploy from branch `main` (or your branch), root `/`.

## Admin Panel

Visit `yoursite.com/admin/` — default password: `vkfoods@2024`

- Add / edit / delete menu items
- Changes save instantly to the browser
